# Idea & prior-work disclosure

Per the buildathon rules, this file declares what existed before the event
started.

## What existed before today

- **The idea only.** We came in having discussed the concept — automatic audio
  description for blind and low-vision viewers, narration placed in the gaps
  between dialogue — as a conversation, not as code.
- **Exploration of Sarvam's public APIs.** Before the event we made exploratory
  calls to Sarvam's documented endpoints (Saaras speech-to-text, Bulbul
  text-to-speech, chat completions) to understand request/response shapes,
  limits, and capabilities. This was familiarisation with the platform, nothing
  more.

## What did NOT exist before today

- No code. Every line in this repository was written during the buildathon —
  the git history is the record.
- No pipeline, no architecture, no prompts, no UI.
- No pre-built assets. Test clips were sourced during the event
  (see `clips/README.md` for provenance).
